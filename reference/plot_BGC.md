# Plot a BGC

Plot a BGC

## Usage

``` r
plot_BGC(
  BGC_json,
  region_id = NULL,
  show_locus_tag = TRUE,
  show_gene_functions = FALSE
)
```

## Arguments

- BGC_json:

  antismash object from `read_antismash_json`

- region_id:

  region_id, default is NULL

- show_locus_tag:

  logical, default is TRUE

- show_gene_functions:

  logical, default is FALSE

## Value

ggplot
