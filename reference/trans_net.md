# Transform the network to metanet object

Transform the network to metanet object

## Usage

``` r
trans_net(big_scape_res, class = "NRPS")
```

## Arguments

- big_scape_res:

  big_scape object from [`read_big_scape_dir()`](read_big_scape_dir.md)

- class:

  default "NRPS", set this to the class you want to extract

## Value

metanet object
