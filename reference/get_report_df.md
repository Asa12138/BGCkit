# Get report dataframe from big_slice_res

Get report dataframe from big_slice_res

## Usage

``` r
get_report_df(big_slice_res, report, distance = 0.4)
```

## Arguments

- big_slice_res:

  big_slice object

- report:

  report name

- distance:

  the threshold to define a bgc in a gcf, default 0.4.

## Value

data.frame
